# מאיפה הכסף

**לפני שבוחרים, בודקים מאיפה מגיע הכסף.**

אתר עברי, נגיש, נייטרלי ופתוח שמרכז מידע רשמי על מימון מפלגות לקראת
הבחירות לכנסת ה־26: תרומות, ערבויות, הלוואות, מימון ציבורי, דמי חבר,
הכנסות רשמיות אחרות וחובות.

הפרויקט מציג מידע שכבר פורסם לציבור. הוא אינו מסיק מניעים, אינו מדרג
מפלגות ואינו ממליץ כיצד להצביע. כל רשומת מימון חייבת קישור למקור
סטטוטורי מאושר; מידע שלא נמצא או טרם אומת מסומן בגלוי.

## מצב הנתונים

גרסה 0.4.0 כוללת 18 מפלגות או רשימות, 998 רשומות רשמיות ל־13 ישויות
זכאיות ושלוש טענות פרופיל עסקי מאומתות. הרשומות הכספיות הושוו
שורה־מול־שורה ליצוא Excel מלא של 1,194 רשומות ממבקר המדינה מ־27 ביולי 2026. נתוני המימון מוצגים מאז היום שלאחר הבחירות לכנסת ה־25
(2 בנובמבר 2022); התקופה הסטטוטורית מסומנת בכל רשומה ואינה משמשת מסנן.
לפי החלטת הפרויקט, ערבויות פעילות נכללות בכותרת „הכנסה מדווחת” ומוצגות
גם בנפרד כהתחייבות מותנית.

למפלגות שלא נמצאו עבורן רשומות בחלון שנבדק מוצג מצב מפורש של
מידע חסר — לא אפס. היעדר רשומה אינו הוכחה שלא הייתה פעילות.

- [דוח התאמה ליצוא הרשמי](docs/reports/source-audit-full-scope-2026-07-27.md)
- [דוח בדיקת פרופילים עסקיים](docs/reports/business-profile-audit-2026-07-27.md)

## פיתוח מקומי

נדרשים Node 22 ו־npm.

```bash
npm install
npm run build:data
npm run dev
```

בדיקה מלאה:

```bash
npm run validate
npm run test:e2e
```
