### קבצים וכללי יסוד

כל קובצי ה־CSV הם UTF-8, מופרדים בפסיקים וכוללים שורת כותרת. סכומי כסף נשמרים
באגורות שלמות בלבד. ערך ריק מציין שהשדה אינו זמין או אינו חל; אין לפרש אותו כאפס.

| קובץ                         | תפקיד                       | מפתח               |
| ---------------------------- | --------------------------- | ------------------ |
| `parties.csv`                | מפלגות, רשימות וסיעות       | `party_id`         |
| `axis_positions.csv`         | סדר ונימוקי הציר            | `axis_position_id` |
| `financing_records.csv`      | רשומות מימון                | `record_id`        |
| `persons.csv`                | אנשים שפורסמו כדין          | `person_id`        |
| `organizations.csv`          | ארגונים וישויות משפטיות     | `org_id`           |
| `person_roles.csv`           | טענות תפקיד עסקיות מתועדות  | `assertion_id`     |
| `sources.csv`                | מטא־נתוני מקור ואימות       | `source_id`        |
| `external_links.csv`         | קישורי הרחבה שאינם ראיה     | `link_id`          |
| `corrections.csv`            | יומן תיקונים                | `correction_id`    |
| `party_financial_scopes.csv` | חלון מדידה ושלמות לכל מפלגה | `party_id`         |
| `party_name_aliases.csv`     | מיפוי שמות מהפרסום לישויות  | `alias_name_he`    |

### `parties.csv`

`mark_he` הוא סימן טקסטואלי ייחודי בן שתיים או שלוש אותיות, המשמש לזיהוי
המפלגה בלי להסתמך על צבע. `brand_color` הוא צבע מותג מתועד; הוא משמש באתר
רק כקו התחלה צר בכרטיס המפלגה וכקו תחתי קטן בציר. בדיקה אוטומטית מוודאת
ייחודיות של הסימנים ומרחק צבע מינימלי בין כל זוג מפלגות.

### `financing_records.csv`

| שדה                            | פירוש                                                                                               |
| ------------------------------ | --------------------------------------------------------------------------------------------------- |
| `category`                     | תרומה, ערבות, הלוואה בנקאית, הלוואה או מקדמה מהכנסת, מימון ציבורי, דמי חבר, הכנסה רשמית אחרת או חוב |
| `amount_agorot`                | סכום חיובי ושלם באגורות                                                                             |
| `event_date`                   | תאריך האירוע כפי שפורסם במקור                                                                       |
| `report_date`                  | תאריך הדיווח; כאשר המקור מפרסם תאריך יחיד בלבד, הוא נשמר גם כאן וההכפלה מצוינת בהערות               |
| `cash_received`                | האם הרשומה מייצגת כסף שהתקבל                                                                        |
| `contingent`                   | האם זו התחייבות מותנית                                                                              |
| `repayment_expected`           | האם צפוי פירעון                                                                                     |
| `in_statutory_election_period` | האם תאריך הרשומה חל בתקופה הסטטוטורית שהחלה ב־18 ביולי 2026                                         |
| `status`                       | פעילה, הוחזרה, מומשה או הוחלפה                                                                      |
| `source_id`                    | מקור רשמי מאושר                                                                                     |
| `official_record_id`           | מזהה בפרסום הרשמי כאשר קיים                                                                         |
| `superseded_by`                | הרשומה הרשמית שהחליפה רשומה זו                                                                      |

ערבות חייבת להיות מותנית ואינה יכולה להיות מסומנת ככסף שהתקבל. לפי החלטת
הפרויקט היא כן נכללת בכותרת „הכנסה מדווחת”, ובמקביל מוצגת תמיד בנפרד
ובהגדרה „התחייבות מותנית”. חוב אינו יכול להיות מסומן ככסף שהתקבל.

### `sources.csv`

`verification_status` מתאר אימות סמנטי ואינו שקול לסטטוס HTTP. `is_primary`
מסמן מקור ראייתי ראשי. מקורות `reference_only` מותרים לזכאות, לציר ולקישורי
הרחבה אך אסורים לרשומות מימון.

### `party_financial_scopes.csv`

`net_position_comparable=true` מותר רק כאשר התקבולים והחובות מכסים אותו חלון
מדידה ואותו היקף. אחרת האתר אינו מציג יתרה נטו. `completeness_status` מתאר אם
האיסוף מלא, חלקי, לא הניב רשומות או עדיין בתהליך.

חלון המדידה הציבורי מתחיל ב־`2022-11-02`, היום שלאחר הבחירות לכנסת ה־25.
`cycleStartDate` הסטטוטורי נשמר בנפרד ואינו מסנן את מערך הנתונים.

### `party_name_aliases.csv`

הקובץ מתעד כיצד שם הישות ביצוא מבקר המדינה ממופה ל־`party_id` באתר. כל מיפוי
כולל נימוק ומקור. „ביחד נצליח” אינה „בנט 2026” ואינה מופיעה בקובץ המיפויים.
